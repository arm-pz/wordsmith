# Wordsmith

A reusable AI skill for distinctive brand names, taglines, and concise marketing copy. Wordsmith aims for sharp, specific language—not generic corporate buzzwords.

## What it does

Wordsmith helps an AI agent:

- Generate and refine brand names, taglines, headlines, and short marketing copy.
- Match the tone and constraints in a brief.
- Avoid empty marketing language and unsupported claims.
- Provide categorized name options and a stress test for naming requests.
